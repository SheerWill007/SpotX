# Recommendations

## Consider SpotX If You Need

- An ad-free experience
- Access to premium features without a Premium subscription
- Interface customization, including themes and colors
- Content filtering, including podcast and audiobook sections
- Reduced analytics and tracking
- Version selection and rollback capabilities
- Developer and advanced configuration access

## Considerations

- Use may violate Spotify's Terms of Service
- Some 2026 features remain untested
- Updates require SpotX reinstallation
- Account suspension or termination is possible
- Some audiobook functionality is unavailable

## Limitations

Do not rely on SpotX if you require:

- Offline downloads, which require an official Premium subscription
- Full audiobook discovery
- Full compliance with Spotify's platform requirements, including DSA and age-verification controls
- Automatic Spotify updates
- Studio by Spotify integration
